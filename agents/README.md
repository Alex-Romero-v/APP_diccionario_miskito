# Agents

Prompts portables para operar este repositorio con SDD.

- `leader.md`: coordina estado y transiciones.
- `spec_author.md`: redacta o corrige documentos SDD.
- `implementer.md`: implementa tareas aprobadas una por una.
- `reviewer.md`: valida evidencia, trazabilidad y checkpoints.

Si una herramienta no tiene subagentes, ejecuta los roles secuencialmente en la
misma conversacion.
